# base_wh GitHub backup scope

This private repository is a fresh-history snapshot of the non-Git main-library
layer at `/home/wuhang/wuhang/base_wh`. It preserves project documentation, process history,
source/test scripts, small data, and project-specific non-generated assets.

Independent nested repositories and local generated state are intentionally not
included. The general exclusions are `main_lib/`, `lib_cite/`, `worktrees/`,
`build/`, results, coverage output, caches, and agent/session state. Those assets
are handled through their own repositories or the private local backup package.

Refer to the server-side audit and SHA-256 manifest for exact provenance.
